Системный анализ веб-ресурса торговой сети «Мария-Ра»

1. Общая информация о ресурсе

Официальный сайт торговой сети:
https://www.maria-ra.ru/

Страница карты сети:
https://www.maria-ra.ru/o-kompanii/karta-seti/

На сайте присутствует раздел «Карта сети», предназначенный
для отображения торговых точек компании.

Для доступа к разделу требуется подтверждение возраста 18+.
После подтверждения возраста пользователю становится доступна
интерактивная карта магазинов.


2. Анализ механизма получения данных

Для определения механизма получения данных о торговых точках
был выполнен анализ сетевых запросов страницы с использованием
инструментов разработчика браузера.

Используемый инструмент анализа:
DevTools → Network → Fetch/XHR

В ходе анализа не были обнаружены отдельные API-запросы,
возвращающие список магазинов в формате JSON.

Обнаруженные запросы носили служебный характер и были
связаны с аналитикой страницы.


3. Анализ страницы карты сети

На странице карты сети используется интерактивная карта,
реализованная на базе сервиса Яндекс.Карты.

На карте реализована кластеризация маркеров, при которой
несколько магазинов объединяются в группы.

Каждый кластер отображается в виде круга с числом,
обозначающим количество магазинов в данной области.

При увеличении масштаба карты кластеры разделяются
на отдельные маркеры магазинов.

При нажатии на маркер отображается карточка магазина,
содержащая адрес торговой точки и режим работы.


4. Получение данных о магазинах

Анализ загружаемых JavaScript файлов показал, что карта
загружает набор JS-файлов, включая main.js, vendor.js
и другие служебные скрипты.

В ходе анализа не были обнаружены отдельные API-запросы,
возвращающие список магазинов.

Это позволяет предположить, что данные о магазинах
встраиваются непосредственно в JavaScript код страницы.


5. Извлекаемые данные

При нажатии на маркер магазина отображается карточка,
содержащая следующие сведения:

- адрес магазина
- населённый пункт
- режим работы магазина

Данные отображаются во всплывающем окне карты.


6. Анализ заголовков HTTP-запросов

В ходе анализа сетевых запросов страницы во вкладке
Network → Fetch/XHR не были обнаружены отдельные
API-запросы, возвращающие список магазинов.

Большинство запросов связано с загрузкой JavaScript
файлов страницы и ресурсов карты.


7. Особенности работы сайта

В ходе анализа были выявлены следующие особенности:

- на сайте используется интерактивная карта
  на базе Яндекс.Карт;
- реализована кластеризация маркеров магазинов;
- данные магазинов отображаются во всплывающих
  карточках карты;
- отдельный API для получения данных о магазинах
  обнаружен не был.


8. Анализ механизмов защиты

В ходе анализа работы сайта установлено, что доступ
к карте сети требует подтверждения возраста 18+.

Других механизмов защиты, препятствующих просмотру
данных о магазинах, обнаружено не было.

CAPTCHA и авторизация для просмотра магазинов
не используются.


9. Предлагаемая стратегия реализации парсера

На основании проведённого системного анализа предлагается
следующая стратегия реализации парсера сети «Мария-Ра»:

1. Получить JavaScript файлы страницы карты сети.
2. Извлечь из JavaScript кода массив данных магазинов.
3. Распарсить координаты и адреса магазинов.
4. Сохранить полученные данные в структуру данных
   для дальнейшей обработки.

Для реализации парсера может быть использован язык
программирования Python.


10. Вывод

В результате системного анализа веб-ресурса торговой
сети «Мария-Ра» установлено, что данные о магазинах
отображаются на интерактивной карте с использованием
кластеризации маркеров.

Отдельный API-запрос со списком магазинов обнаружен
не был. Предположительно данные магазинов встраиваются
в JavaScript код страницы карты сети.

Таким образом, получение данных о магазинах возможно
посредством анализа JavaScript кода страницы и извлечения
данных о торговых точках.
