# Known Issues

## Monetka

Некоторые магазины или страницы магазинов у Монетки могут возвращать HTTP 404.

Ожидаемое поведение проекта:
- парсер не должен падать на таких записях
- такие записи должны логироваться
- сбор остальных магазинов должен продолжаться
- если часть полей можно получить из общего списка без перехода на 404-страницу, запись должна сохраняться частично
- если магазин недоступен полностью, это должно быть отражено в логах и/или статусе записи
