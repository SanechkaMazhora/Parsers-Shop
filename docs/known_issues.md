# Known Issues

## Monetka

Некоторые магазины или страницы магазинов у Монетки могут возвращать HTTP 404.

Ожидаемое поведение проекта:
- парсер не должен падать на таких записях
- такие записи должны логироваться
- сбор остальных магазинов должен продолжаться
- если часть полей можно получить из общего списка без перехода на 404-страницу, запись должна сохраняться частично
- если магазин недоступен полностью, это должно быть отражено в логах и/или статусе записи

Практическое ограничение:
- если `404` возвращает detail page магазина, проект может сохранить частичную запись из city list
- если `404` возвращает сама city page и списка магазинов на ней нет, проект не выдумывает записи и только логирует пропуск города

## Maria-Ra

- `region` доступен не для всех точек и в таких случаях сохраняется как `None`
- часть `city` можно достать только из строки адреса; если источник не дает город явно и адрес не содержит надежного признака населенного пункта, проект оставляет `city=None`

## Diff / baseline

- первый запуск не считается бизнес-diff: он только инициализирует baseline snapshot
- корректный лист `Изменения` появляется начиная со второго полного запуска по тому же snapshot
