Системный анализ веб-ресурса торговой сети «Красное&Белое»

1. Общая информация о ресурсе

Официальный сайт торговой сети:
https://krasnoeibeloe.ru

Страница с информацией о торговых точках:
https://krasnoeibeloe.ru/address/

При первом посещении сайта отображается окно подтверждения возраста (18+).
После подтверждения пользователь получает доступ к разделу со списком магазинов.


2. Анализ механизма получения данных

Для определения механизма получения данных о торговых точках был выполнен
анализ сетевых запросов страницы с использованием инструментов разработчика браузера.

Используемый инструмент анализа:
DevTools → Network → Fetch/XHR

В ходе анализа установлено, что сайт использует REST API для получения
данных о городах и магазинах.


3. Получение списка городов

При загрузке страницы магазинов выполняется запрос:

list/

Данный запрос возвращает ответ в формате JSON, содержащий список городов.

Пример структуры ответа:

{
  "cities": [
    {
      "id": 778,
      "name": "Название города",
      "regionId": 777
    }
  ]
}

Описание полей:

• id — уникальный идентификатор города
• name — название города
• regionId — идентификатор региона

Полученный список используется сайтом для формирования списка городов
при выборе населённого пункта.


4. Получение списка магазинов

После выбора города на странице выполняется запрос:

https://krasnoeibeloe.ru/api/cities/{city_id}/shops/

где:

• city_id — идентификатор выбранного города

Характеристики запроса:

• Метод запроса — GET
• Формат ответа — application/json

Пример структуры ответа:

{
  "id": 5456,
  "num": "20",
  "shopNum": "20",
  "address": "Адрес магазина",
  "cityId": 143,
  "lat": 55.12135,
  "lng": 61.434228,
  "workTime": {
    "week": ["09:00", "22:05"]
  }
}


5. Извлекаемые данные

Ответ API содержит информацию о торговых точках сети.

Основные извлекаемые поля:

• id — идентификатор магазина
• num — номер магазина
• shopNum — номер торговой точки
• address — полный адрес магазина
• cityId — идентификатор города
• lat — географическая широта
• lng — географическая долгота
• workTime — режим работы магазина

Данные соответствуют требованиям технического задания, в котором
необходимо получать информацию о местоположении торговых точек,
режиме работы и координатах магазинов.


6. Анализ заголовков HTTP-запросов

В ходе анализа заголовков HTTP-запросов установлено:

• Метод запроса — GET
• Тип ответа сервера — application/json
• Используемый веб-сервер — nginx
• Система управления сайтом — Bitrix Site Manager

Также используются стандартные cookies сессии:

• PHPSESSID
• BITRIX_CONVERSION_CONTEXT

Обязательная авторизация или токены доступа для выполнения запросов
не требуются.


7. Особенности работы сайта

В ходе анализа выявлены следующие особенности:

• при первом посещении сайта отображается окно подтверждения возраста 18+
• данные о магазинах запрашиваются отдельно для каждого города
• данные передаются через REST API
• ограничения доступа, связанные с авторизацией, не обнаружены


8. Анализ механизмов защиты

В ходе анализа работы сайта были исследованы возможные механизмы защиты,
которые могут препятствовать автоматизированному сбору данных.

При выполнении сетевых запросов к API не были обнаружены следующие
механизмы защиты:

• CAPTCHA
• ограничения частоты запросов (rate limiting)
• блокировки по IP-адресу
• блокировки по User-Agent
• обязательная авторизация пользователя

Запросы к API выполняются без необходимости передачи токенов доступа.
В HTTP-заголовках используются стандартные cookies сессии
(PHPSESSID и BITRIX_CONVERSION_CONTEXT), характерные для сайтов,
работающих на системе управления Bitrix.

Таким образом, доступ к данным о магазинах осуществляется свободно
через открытые API-запросы.


9. Предлагаемая стратегия реализации парсера

На основании проведённого системного анализа предлагается следующая
стратегия реализации парсера торговой сети «Красное&Белое»:

1. Выполнить HTTP-запрос list/ для получения списка городов.
2. Из полученного ответа извлечь идентификаторы городов (city_id).
3. Для каждого города выполнить HTTP-запрос следующего вида:
   https://krasnoeibeloe.ru/api/cities/{city_id}/shops/
4. Получить список магазинов выбранного города.
5. Извлечь необходимые данные о торговых точках:
   • адрес магазина
   • координаты (lat, lng)
   • режим работы
   • номер магазина
6. Сохранить полученные данные в структуру данных для дальнейшей
обработки и формирования итогового отчёта.

Для реализации парсера планируется использовать язык программирования
Python и библиотеку requests для выполнения HTTP-запросов.


10. Вывод

В результате системного анализа установлено, что данные о торговых точках
сети «Красное&Белое» доступны через REST API.

Основными API-запросами являются:

• list/ — получение списка городов
• /api/cities/{city_id}/shops/ — получение списка магазинов выбранного города

Ответы сервера передаются в формате JSON и содержат основные сведения
о торговых точках, включая адрес, координаты и режим работы.

В ходе анализа не были обнаружены механизмы защиты, препятствующие
автоматизированному сбору данных. Использование браузерной автоматизации
для данного сайта не требуется.

Таким образом, реализация парсера сети «Красное&Белое» может быть выполнена
с использованием прямых HTTP-запросов к API с последовательным обходом
списка городов.
