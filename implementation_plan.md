# Implementation Plan – Retail Chains Parser

## 1. Цель проекта

Разработать систему парсеров для получения информации о магазинах
трёх торговых сетей:

- Красное & Белое
- Монетка
- Мария-Ра

Парсеры должны автоматически извлекать информацию о торговых точках
и сохранять её в единую структуру данных с последующим экспортом
в Excel.

Проект должен быть реализован на языке Python.


--------------------------------------------------

## 2. Единый формат выходных данных

Все парсеры должны возвращать данные в едином формате.

Каждая запись о магазине должна содержать следующие поля:

network — название сети  
region — регион  
city — город  
address — адрес магазина  
work_time — режим работы  
lat — широта  
lng — долгота  
phone — телефон (если доступен)  
store_format — формат магазина (если доступен)  
status — статус магазина (если доступен)  
source_url — URL страницы источника  
parsed_at — дата и время парсинга


Пример структуры записи:

{
  "network": "Красное & Белое",
  "region": "Новосибирская область",
  "city": "Новосибирск",
  "address": "ул. Ленина, 10",
  "work_time": "09:00–22:00",
  "lat": 55.0302,
  "lng": 82.9204,
  "phone": null,
  "store_format": null,
  "status": "open",
  "source_url": "https://...",
  "parsed_at": "2026-03-09T12:00:00"
}

## 3. Реализация парсера «Красное & Белое»

Источник данных:

https://krasnoeibeloe.ru/api/

Сайт использует REST API для получения информации о магазинах.

Основной endpoint:

/api/cities/{city_id}/shops/

Подход реализации:

1. Получить список городов через API.
2. Для каждого города получить список магазинов.
3. Из JSON извлечь необходимые поля.
4. Преобразовать данные к единому формату.

Используемые технологии:

- requests
- JSON parsing

Playwright или Selenium не требуется.


--------------------------------------------------

## 4. Реализация парсера «Монетка»

Источник данных:

https://www.monetka.ru/

Страница карты магазинов:

https://www.monetka.ru/shops_map/

Архитектура сайта:

- для каждого города существует отдельная страница
- для каждого магазина существует отдельная страница

Данные о магазине находятся непосредственно в HTML.

Подход реализации:

1. Получить список городов.
2. Перейти на страницу каждого города.
3. Извлечь ссылки на страницы магазинов.
4. Для каждой страницы магазина извлечь:
   - адрес
   - город
   - режим работы
   - формат магазина

Используемые технологии:

- requests
- BeautifulSoup


--------------------------------------------------

## 5. Реализация парсера «Мария-Ра»

Источник данных:

https://www.maria-ra.ru/o-kompanii/karta-seti/

На сайте используется интерактивная карта на базе Яндекс.Карт.

Особенности:

- используется кластеризация маркеров
- данные о магазинах отображаются во всплывающих карточках карты
- API-endpoint со списком магазинов не обнаружен

Предполагаемый механизм:

данные магазинов встроены в JavaScript код страницы.

Подход реализации:

1. Скачать HTML страницы карты сети.
2. Найти JavaScript блок с данными магазинов.
3. Извлечь координаты и адреса магазинов.
4. Преобразовать данные к единому формату.

Fallback-подход:

если извлечение из JavaScript невозможно,
использовать Playwright для получения данных из DOM.
